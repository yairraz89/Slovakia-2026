## Google Maps

המפתח כבר מוגדר ב-[`assets/js/config.js`](assets/js/config.js) והמפה עובדת.

### הגבלת המפתח — מוגדרת ומאומתת ✅

מפתח Maps JS נשלח לדפדפן של כל מי שפותח את האתר, ולכן הוא **ציבורי מעצם תכנונו** — אי אפשר להסתיר אותו. מה שמגן עליו זו הגבלה לפי דומיין, לא סודיות.

ההגבלה הוגדרה ואומתה ב-5.8.2026: טעינה של אותו אתר מפורט לא-מורשה (`localhost:4174`) נדחתה עם `RefererNotAllowedMapError`, בעוד הפורט המורשה והאתר החי עובדים.

ההגדרה ב-[Google Cloud Console](https://console.cloud.google.com/google/maps-apis/credentials):

- *Application restrictions* ← **Websites**: `https://yairraz89.github.io/*` ו-`http://localhost:4173/*`
- *API restrictions* ← **Maps JavaScript API** בלבד

**אם מוסיפים דומיין חדש** (למשל דומיין מותאם אישית) — חובה להוסיף אותו גם לרשימת ה-Websites, אחרת המפה לא תיטען שם.

מומלץ גם: תקרת מכסה יומית על `Map loads per day` (זה מה שבאמת עוצר חיוב חריג — Budget alert רק שולח מייל).

אם המפתח ידלוף או שתרצו להחליף אותו: צרו מפתח חדש בקונסולה, עדכנו את `config.js`, ומחקו את הישן.

### אם המפה מפסיקה לעבוד

מסך המפה יציג הוראות ורשימה מלאה של הנקודות עם קישורי ניווט, במקום להישבר. הסיבות הנפוצות: המפתח נמחק, החיוב בפרויקט כובה, או שהדומיין החדש לא נוסף להגבלות.

### הגדרות נוספות ב-`config.js`

| שדה | מה זה עושה |
|---|---|
| `MAP_ID` | אופציונלי. אם ימולא — סמנים מסוג Advanced Markers (יפים יותר), אבל צבעי המפה נשלטים מ-Google Cloud ולא מהקוד. ריק = סמנים קלאסיים + מצב כהה אוטומטי |
| `MAP_LANGUAGE` | `'iw'` עברית · `'sk'` סלובקית (כמו על השלטים בשטח) · `'en'` אנגלית |
| `MAP_TYPE` | `'terrain'` (ברירת מחדל, הכי טוב להרים) · `'roadmap'` · `'hybrid'` |

## עריכת התוכן

**כל התוכן נמצא בקובץ אחד: [`assets/js/data.js`](assets/js/data.js).** אין צורך לגעת בשום מקום אחר.

מבנה הקובץ:

- `meta` — כותרת, תאריכים, פרטי הקבוצה
- `categories` — סוגי הנקודות (צבע + אייקון לכל סוג)
- `pois` — נקודות העניין. כל נקודה: `id`, `name`, `local`, `lat`, `lng`, `cat`, `days`, `desc`, `tips`, ואופציונלית `walk` / `driveTo` (ראו למטה)
- `days` — לוח הימים. כל יום: `n`, `date`, `title`, `weather`, `drive`, `summary`, `items[]`, ואפשר `alt` לחלופה
- `rain` — עיקרון מזג האוויר ושתי אופציות הגשם
- `info` — בלוקי המידע המעשי
- `verify` — מה לאמת לפני הנסיעה
- `checklist` — פריטי הצ׳קליסט (`g` = קבוצה, `t` = טקסט)

### להוסיף נקודה חדשה

מוסיפים אובייקט למערך `pois`:

```js
{
  id: 'my-place',
  name: 'שם בעברית',
  local: 'Local Name',
  lat: 49.0, lng: 19.5,
  cat: 'nature',          // מפתח מתוך categories
  days: [3],              // באילו ימים היא רלוונטית ([] = לא משויכת)
  desc: 'תיאור קצר.',
  tips: ['טיפ ראשון', 'טיפ שני'],
}
```

כדי לקשר אותה מתוך לוח היום, מוסיפים `poi: 'my-place'` לפריט ב-`items` של אותו יום.

### לסמן נקודה כ"רעיון נוסף"

`bonus: true` + `days: []` — היא תופיע בפילטר "✨ רעיונות נוספים" ולא בשום יום.

### מסלול הנסיעה היומי

כפתור "מסלול הנסיעה של היום" נבנה אוטומטית מהתחנות של אותו יום, לפי הסדר, ומתחיל ומסתיים בלינה. שלושה כללים שומרים על מסלול שאפשר באמת לנסוע בו:

- פריט מסומן `optional: true` **לא** נכנס למסלול (הוא "אולי", לא חלק מהתוכנית)
- נקודה עם `walk: true` מדולגת — יעד שמגיעים אליו רק ברגל או ברכבל (חוות Podžiar, מגדל התצפית של פבצ׳ינה לֶהוֹטה, לומניצקי שטיט)
- נקודה עם `driveTo: '<id>'` מוחלפת בחניון / תחנת הרכבל שלה. למשל פסגת צ׳ופוק ← רכבל יאסנה, נקיק יאנושיק ← חניון מלון Diery

יום עם `noRoute: true` (שבת) לא מקבל כפתור בכלל.

## ניווט

בכל נקודה יש שני כפתורים, ושניהם עובדים אחרת:

- **גוגל מפות** — חיפוש לפי השם המקומי (`Demänovská jaskyňa slobody`), עם הקואורדינטות כרמז. פותח את היעד בכרטיס מקום.
- **Waze** — ניווט ישיר לקואורדינטות (`waze.com/ul?ll=…&navigate=yes`). נפתח באפליקציה אם היא מותקנת, אחרת ב-waze.com. Waze לא תומך בחיפוש שם בקישור ניווט ישיר, ולכן הקישור מבוסס קואורדינטות בלבד — וגם לא תומך במסלול רב-עצירות, ולכן כפתור "מסלול הנסיעה של היום" הוא גוגל מפות בלבד.

### דיוק הקואורדינטות

כל 35 הקואורדינטות אומתו מול ה-Geocoding API של Google (5.8.2026) — כל נקודה הוצלבה מול תוצאת החיפוש של השם המקומי, ו-34 מהן עודכנו לערך ש-Google מחזירה. חלקן זזו 1–3 ק״מ (טטרלנדיה, בכלדקה, נקיק יאנושיק, Žiarce, ZooKontakt). בנוסף כל נקודה עברה reverse geocoding לוודא שהיא נופלת במדינה הנכונה.

עדיין שווה לזכור: לכמה נקודות Google מחזירה מרכז יישוב ולא כתובת מדויקת (הלינה = מרכז הכפר פבצ׳ינה לֶהוֹטה, כי כתובת הבית עצמו לא ידועה; טטרה בוב ומוזיאון האשליות = מרכז העיירה). כשתדעו את הכתובת המדויקת של הבית — עדכנו את `lodging` ב-`data.js`.
